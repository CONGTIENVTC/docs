Setting up your Google account correctly from the start ensures smooth access to all platform features, including the REST API, cloud services, and productivity tools. This guide covers everything from initial registration to API key generation and security best practices.

<Steps>
  <Step title="Sign Up at accounts.google.com">
    Visit [accounts.google.com](https://accounts.google.com) and click **Create account**. Choose whether you're creating a personal account or one for business use. Enter your first and last name, select a Gmail address, and create a strong password. Click **Next** to proceed.
  </Step>
  <Step title="Verify Your Email">
    Google will send a verification code to the email address associated with your new account. Enter the code on the verification screen within 10 minutes. Once confirmed, your account will be fully activated and ready to access all Google services.
  </Step>
  <Step title="Enable API Access">
    To use Google's REST API, you need to enable it in the developer console:

    1. Go to the [Google Cloud Console](https://console.cloud.google.com).
    2. Create a new **Project** (or select an existing one).
    3. Navigate to **APIs & Services → Library**.
    4. Search for the specific Google API you want to use (e.g., *Custom Search API*) and click **Enable**.
  </Step>
  <Step title="Generate Your First API Key">
    With API access enabled on your project:

    1. In the Cloud Console, navigate to **APIs & Services → Credentials**.
    2. Click **Create Credentials** and choose **API key** from the dropdown.
    3. Your new key will appear — copy it immediately and save it securely.
    4. Optionally, click **Restrict Key** to limit the key to specific APIs or IP addresses, which is strongly recommended for production use.
  </Step>
  <Step title="Set Up Two-Factor Authentication (Recommended)">
    Protecting your account with two-factor authentication (2FA) adds a critical layer of security:

    1. Go to your [Google Account Security settings](https://myaccount.google.com/security).
    2. Under **How you sign in to Google**, click **2-Step Verification**.
    3. Follow the prompts to link your phone number or an authenticator app (such as Google Authenticator).
    4. Complete the enrollment and save your backup codes in a safe location.
  </Step>
</Steps>

## Managing API Keys

### Creating a New Key

Navigate to **APIs & Services → Credentials** in the Cloud Console and click **Create Credentials → API key**. Each project can have multiple keys — use separate keys for development and production environments to simplify access management.

### Rotating a Key

To rotate a key, generate a new one following the steps above, update your application or environment variables to use the new key, verify everything is working, and then revoke the old key. Aim to rotate keys every 90 days as a security best practice.

### Revoking a Key

To revoke a key, open the **Credentials** page, find the key you want to remove, click the **Delete** (trash) icon, and confirm the deletion. Revoked keys stop working immediately, so make sure all dependent services are updated before revoking.

<Warning>
  Never commit API keys to version control, hard-code them in client-side code, or share them via email or chat. If a key is accidentally exposed, revoke it immediately and generate a replacement. Use environment variables or a secrets manager (such as Google Secret Manager) to store keys securely.
</Warning>

<Tip>
  Establish a regular key rotation schedule — every 90 days is a common industry standard. You can set calendar reminders or use automated secret rotation tools to ensure keys are refreshed before they become a security liability. Restrict each key to only the APIs and IP ranges it needs using the **Key Restrictions** settings in the Cloud Console.
</Tip>
