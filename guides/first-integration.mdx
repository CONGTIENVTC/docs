In this guide, you'll build a complete integration with the Google REST API — starting from authentication, performing your first search, and processing the results in your application. By the end, you'll have a working integration that queries Google's search endpoint and handles responses and errors gracefully.

<Steps>
  <Step title="Prerequisites">
    Before you begin, make sure you have the following ready:

    - **A Google API key** — Generate one from the [Google Developer Console](https://console.developers.google.com). Keep it secure and never commit it to version control.
    - **Your preferred language** — This guide includes examples for **curl**, **Python**, and **JavaScript/Node.js**. Choose the one that best fits your stack.
    - A basic understanding of REST APIs and HTTP request/response cycles.
  </Step>

  <Step title="Authenticate">
    All requests to the Google API must be authenticated using your API key. Pass it as a Bearer token in the `Authorization` header:

    ```http
    Authorization: Bearer YOUR_API_KEY
    ```

    This header must be included with every API request. Requests without a valid key will receive a `401 Unauthorized` response.

    <Warning>
      Never expose your API key in client-side code or public repositories. Use environment variables or a secrets manager to handle credentials securely.
    </Warning>
  </Step>

  <Step title="Perform a Search">
    With authentication in place, you can now run your first search. Send a `GET` request to the `/search` endpoint with your query as a URL-encoded parameter:

    ```http
    GET /search?q=your+query
    ```

    You can also combine additional query parameters to refine results:

    | Parameter  | Type   | Description                              |
    |------------|--------|------------------------------------------|
    | `q`        | string | The search query string *(required)*     |
    | `lang`     | string | Language code, e.g. `en`, `fr`, `de`    |
    | `region`   | string | Region code, e.g. `us`, `gb`, `au`      |
    | `type`     | string | Content type: `web`, `image`, `news`    |
    | `page`     | number | Page number for paginated results        |
    | `per_page` | number | Results per page (max: 50)               |
  </Step>

  <Step title="Parse the Response">
    A successful request returns a `200 OK` response with a JSON body. The top-level `results` array contains the search hits — iterate over it to access each item's title, URL, and snippet:

    ```json
    {
      "query": "your query",
      "total_results": 1420000,
      "page": 1,
      "per_page": 10,
      "results": [
        {
          "id": "res_01HXZ4K9MNBVCXP",
          "title": "Example Result Title",
          "url": "https://example.com/page",
          "snippet": "A short description of the page content matching your query...",
          "published_at": "2024-11-15T08:30:00Z",
          "content_type": "web"
        },
        {
          "id": "res_02HXZ4K9MNBVCXQ",
          "title": "Another Result Title",
          "url": "https://anotherexample.com/article",
          "snippet": "Additional context about the matching page content...",
          "published_at": "2024-10-22T14:15:00Z",
          "content_type": "web"
        }
      ],
      "meta": {
        "request_id": "req_9fXm3pLqRtYw",
        "response_time_ms": 142
      }
    }
    ```

    Access each result's fields like `result.title`, `result.url`, and `result.snippet` to render or process the data in your application.
  </Step>

  <Step title="Handle Errors">
    The Google API uses standard HTTP status codes to signal errors. Your integration should handle these cases explicitly:

    | Status Code | Meaning              | Recommended Action                                        |
    |-------------|----------------------|-----------------------------------------------------------|
    | `401`       | Unauthorized         | Check that your API key is valid and correctly formatted. |
    | `429`       | Too Many Requests    | You've exceeded your rate limit — back off and retry after the period specified in the `Retry-After` header. |
    | `500`       | Internal Server Error | A server-side issue occurred. Retry with exponential backoff. |

    All error responses include a JSON body with a `code` and `message` field to help diagnose the issue:

    ```json
    {
      "error": {
        "code": "rate_limit_exceeded",
        "message": "You have exceeded your plan's request quota. Please retry after 60 seconds.",
        "retry_after": 60
      }
    }
    ```
  </Step>
</Steps>

## Code Examples

The following examples show a complete integration — authenticating, sending a search request, and printing results — in three popular languages.

<CodeGroup>

```bash curl
curl -X GET "https://api.google.com/search?q=your+query" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Accept: application/json"
```

```python Python
import os
import requests

API_KEY = os.environ.get("GOOGLE_API_KEY")
BASE_URL = "https://api.google.com"

def search(query: str) -> dict:
    headers = {
        "Authorization": f"Bearer {API_KEY}",
        "Accept": "application/json",
    }
    params = {"q": query}

    response = requests.get(f"{BASE_URL}/search", headers=headers, params=params)

    if response.status_code == 401:
        raise ValueError("Invalid API key. Check your GOOGLE_API_KEY environment variable.")
    elif response.status_code == 429:
        retry_after = response.headers.get("Retry-After", "unknown")
        raise RuntimeError(f"Rate limit exceeded. Retry after {retry_after} seconds.")
    elif response.status_code >= 500:
        raise RuntimeError("Server error. Please try again later.")

    response.raise_for_status()
    return response.json()


if __name__ == "__main__":
    data = search("your query")
    for result in data.get("results", []):
        print(f"{result['title']}\n{result['url']}\n{result['snippet']}\n")
```

```javascript Node.js
import fetch from "node-fetch"; // or use the built-in fetch in Node 18+

const API_KEY = process.env.GOOGLE_API_KEY;
const BASE_URL = "https://api.google.com";

async function search(query) {
  const url = new URL(`${BASE_URL}/search`);
  url.searchParams.set("q", query);

  const response = await fetch(url.toString(), {
    method: "GET",
    headers: {
      Authorization: `Bearer ${API_KEY}`,
      Accept: "application/json",
    },
  });

  if (response.status === 401) {
    throw new Error("Invalid API key. Check your GOOGLE_API_KEY environment variable.");
  }
  if (response.status === 429) {
    const retryAfter = response.headers.get("Retry-After") ?? "unknown";
    throw new Error(`Rate limit exceeded. Retry after ${retryAfter} seconds.`);
  }
  if (response.status >= 500) {
    throw new Error("Server error. Please try again later.");
  }

  const data = await response.json();
  return data;
}

// Run the search
search("your query").then((data) => {
  for (const result of data.results ?? []) {
    console.log(`${result.title}\n${result.url}\n${result.snippet}\n`);
  }
});
```

</CodeGroup>

<Note>
  The `/search` endpoint returns paginated results. Use the `page` and `per_page` query parameters to navigate through large result sets. The `total_results` field in the response indicates the full count of matching documents. For complete details on all available query parameters and response fields, see the [full API reference](/api/overview).
</Note>
