This guide walks you through everything you need to go from zero to your first successful Google API call. By the end, you'll have a working account, a valid API key, and a real search response in hand — all in under five minutes.

<Steps>
  <Step title="Create Your Account">
    Head to [accounts.google.com](https://accounts.google.com) and click **Create account**. Fill in your name, choose a Gmail address, and set a strong password. Once submitted, Google will send a verification email — confirm it to unlock full platform and API access.

    For a detailed walkthrough including workspace configuration and two-factor authentication setup, see the [Account Setup guide](/account-setup).
  </Step>
  <Step title="Get Your API Key">
    Once your account is active:

    1. Sign in and open the [Google Cloud Console](https://console.cloud.google.com).
    2. Select or create a **Project** from the top navigation bar.
    3. In the left sidebar, navigate to **APIs & Services → Credentials**.
    4. Click **Create Credentials** and select **API key**.
    5. Copy the generated key and store it somewhere safe — you'll use it in every API request.

    <Warning>
      Never expose your API key in client-side code or public repositories. Treat it like a password.
    </Warning>
  </Step>
  <Step title="Make Your First API Call">
    With your API key ready, you can run a search query against Google's API. The example below calls `GET /search` with a query parameter of `hello`:

    <CodeGroup>
      ```bash curl
      curl -G "https://api.google.com/search" \
        --data-urlencode "q=hello" \
        -H "Authorization: Bearer YOUR_API_KEY"
      ```

      ```python Python
      import requests

      API_KEY = "YOUR_API_KEY"

      response = requests.get(
          "https://api.google.com/search",
          params={"q": "hello"},
          headers={"Authorization": f"Bearer {API_KEY}"},
      )

      data = response.json()
      print(data)
      ```
    </CodeGroup>

    Replace `YOUR_API_KEY` with the key you generated in the previous step.
  </Step>
  <Step title="Handle the Response">
    A successful request returns a `200 OK` status and a JSON body structured like this:

    ```json
    {
      "status": "success",
      "query": "hello",
      "total_results": 4820000000,
      "results": [
        {
          "title": "Hello - Wikipedia",
          "url": "https://en.wikipedia.org/wiki/Hello",
          "snippet": "Hello is a salutation or greeting in the English language..."
        },
        {
          "title": "Hello World — Getting Started Guide",
          "url": "https://developers.google.com/hello-world",
          "snippet": "A classic starting point for every developer exploring the Google API..."
        }
      ],
      "page": 1,
      "per_page": 10
    }
    ```

    Use the `results` array to display, process, or store the search data in your application. Paginate through results using the `page` query parameter.
  </Step>
</Steps>

<Note>
  Google's API enforces rate limits based on your account tier. Free accounts are limited to **100 requests per day**. Standard and Enterprise plans offer higher quotas. If you exceed your limit, the API returns a `429 Too Many Requests` response. See the [API Reference](/api/overview) for full rate limit details and best practices for managing quota.
</Note>
